# AdBlocker
一个基于 Android 无障碍服务的本地广告拦截工具。 不联网、不上传、不收集，所有识别逻辑均在设备本地完成。
## ✨ 功能特性

- 🚫 自动跳过开屏广告（关键词 / 控件ID / 坐标三级匹配）
- 📱 秒退摇一摇广告页
- 📋 用户自定义规则库，支持导入导出
- 🎚️ 四档拦截强度（普通 / 中等 / 强力 / 自定义）
- 📊 每个应用可单独设置强度
- 🛡️ 白名单保护，避免误拦
- ⚠️ 流氓软件识别（高频弹窗 + 异常名称）
- 🔒 阻止自动安装
- 📝 可疑节点日志，一键生成规则
- 🌙 深色模式自动跟随系统

## 📱 系统要求

- Android 7.0 (API 24) 及以上
- 需开启无障碍服务
- 建议加入电池优化白名单

## 📦 安装

1. 下载 `app-release.apk`
2. 在手机设置里允许"安装未知来源应用"
3. 点击 APK 安装
4. 打开 App，按引导开启无障碍服务

## 🚀 首次使用

1. 打开 App → 点击"开启无障碍服务"
2. 在系统设置找到"广告拦截助手" → 打开开关
3. 返回 App → 状态点变绿
4. 点击"加入电池优化白名单"
5. 进入"设置 → 拦截强度"选"强力"
6. 打开一个带广告的 App 测试

## 🔐 隐私

- 不联网
- 不上传任何数据
- 不收集设备信息
- 无障碍服务读取的屏幕内容仅在本地内存处理
