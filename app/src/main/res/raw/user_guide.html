使用指南

一、安装

  1. 下载 app-release.apk
  2. 手机设置 → 安全 → 允许安装未知来源应用
  3. 点击 APK 安装
  4. 打开 App

二、首次配置

步骤 1：开启无障碍服务

  • 首页点击"开启无障碍服务"
  • 系统会跳转到无障碍设置页
  • 找到"广告拦截助手"
  • 点击开关，确认"允许"
  • 返回 App，顶部状态点变绿
找不到入口？
小米/Redmi：设置 → 更多设置 → 无障碍 → 已下载的应用
华为/荣耀：设置 → 辅助功能 → 无障碍 → 已安装的服务
OPPO/vivo：设置 → 系统设置 → 无障碍
三星：设置 → 辅助功能 → 已安装的服务

步骤 2：加入电池白名单

  • 首页点击"加入电池优化白名单"
  • 选择"允许"
  • 部分 ROM 需在"设置 → 应用管理 → 广告拦截助手 → 自启动"中额外允许

步骤 3：选择拦截强度

  • 进入"设置 → 拦截强度"
  • 新手推荐"强力"
  • 遇到误触可降到"中等"

三、日常使用

自动拦截（无需操作）

开启服务后，App 会在后台自动：

  • 识别并关闭开屏广告
  • 秒退摇一摇广告页
  • 阻止自动安装
  • 记录可疑节点

手动配置

应用列表：

  • 查看手机所有应用
  • 勾选白名单 → 该应用完全不被拦截
  • 点击应用 → 进入详情页单独配置

规则库：

  • 添加/编辑/删除自定义规则
  • 导入/导出规则文件

日志：

  • 查看可疑节点记录
  • 点击日志项一键生成规则

四、常见场景

场景 1：某个 App 的广告跳不过

  1. 打开该 App，让广告出现
  2. 回到本 App → 设置 → 日志
  3. 找到刚才的广告节点
  4. 点击它 → 生成规则
  5. 回到规则库确认规则已启用

场景 2：正常按钮被误点

  1. 进入"设置 → 应用列表"
  2. 找到该应用
  3. 勾选白名单（或进入详情页降低强度）
  4. 该应用不再被拦截

场景 3：想给朋友分享规则

  1. 设置 → 规则库 → 导出
  2. 选择保存位置，生成 .json 文件
  3. 把文件发给朋友
  4. 朋友在本 App 里"导入"即可

场景 4：觉得 App 有问题想清空

  1. 设置 → 清空所有数据
  2. 确认 → 所有规则、白名单、日志被删除
  3. 到系统设置里关闭无障碍服务再重新开启

五、疑难解答

Q: 服务开了但广告还在跳？

A: 1. 检查强度是否为"强力"；2. 检查该应用是否在"白名单"中；3. 到"日志"查看是否识别到了广告节点。

Q: 服务自动关闭？

A: 加入电池优化白名单，并在"自启动管理"中允许本 App。

Q: 应用列表为空？

A: Android 11+ 需授予 QUERY_ALL_PACKAGES。重装 App 或在系统设置里允许。

Q: 深色模式不生效？

A: Android 7~9 系统无深色模式，App 始终浅色。Android 10+ 跟随系统。

Q: 卸载后还有残留？

A: 本 App 所有数据存在本地，卸载后系统自动清除。规则导出文件在用户指定位置，需手动删除。

六、卸载

  1. 系统设置 → 无障碍 → 关闭"广告拦截助手"
  2. 系统设置 → 应用管理 → 广告拦截助手 → 卸载
  3. 或长按图标拖到"卸载"
