新增

  • 基于无障碍服务的广告自动拦截
  • 关键词 / 控件ID / 坐标三级匹配
  • 秒退广告 Activity（摇一摇核心）
  • 摇一摇 WebView 特征识别
  • 阻止自动安装
  • 规则库（增删改 + 导入导出）
  • 四档拦截强度（普通/中等/强力/自定义）
  • 应用级强度覆盖
  • 应用级自定义开关
  • 应用列表（搜索 + 系统应用过滤）
  • 应用白名单
  • 应用详情页
  • 可疑节点日志 + 一键生成规则
  • 流氓软件识别
  • 深色模式（Android 10+）
  • 设置页 + 关于页
  • 内置隐私政策 / 权限说明 / 使用指南 / 兼容性测试清单

支持

  • Android 7.0 (API 24) 至 Android 14 (API 34)
  • 简体中文界面

已知限制

  • Android 7~9 不支持深色模式
  • 部分 ROM 不返回 viewId，需依赖关键词
  • 低端机上秒退成功率较低
